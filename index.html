Ein Launcher, der Roblox nicht anfasst.

Brickstrap startet den offiziellen Roblox-Client von außen. Du wählst deinen Server selbst, stellst Grafik und Leistung ein und siehst, wo deine Freunde spielen. Kostenlos für Windows.

Neueste Version Windows 10 und 11

Brickstrap machtüber Web-APIs und Dateien von Roblox

  • Server selbst wählenKleinster Server, bester Ping oder genau der, den du willst. Ein Klick tritt bei.
  • FastFlags mit fertigen StufenMax FPS, Ausgewogen, Hohe Qualität. Nur Flags, die Roblox offiziell zulässt.
  • Freunde und SpielerSieh, wer online ist, tritt bei und schau dir Profile und Abzeichen an.
  • Discord-StatusSpiel, Server-Region und Spielerzahl, mit Knopf zum Beitreten.
  • Spielzeit und „Wieder beitreten“Gelesen aus der Logdatei von Roblox. Zurück auf den letzten Server mit einem Klick.

Brickstrap macht niedarum bleibt dein Konto sicher

  • Code in Roblox einschleusenKeine DLL, kein Hook, kein Overlay im Roblox-Prozess.
  • Speicher des Clients lesen oder schreibenAuch kein FPS-Unlocker und keine „Speicher-Bereinigung“.
  • Die Roblox-Datei verändernDer offizielle Client bleibt, wie er ist.
  • Für dich klicken oder tippenKeine Macros, keine automatischen Eingaben.
  • Deine Anmeldung weitergebenDu meldest dich auf der echten Seite von Roblox an. Das Cookie bleibt verschlüsselt auf deinem PC und geht nur an roblox.com.

In einer Minute startklar.

Keine Installation, kein Installer. Eine Datei, die sich selbst einrichtet.

  1. Laden

    Die neueste Brickstrap_…_x64.exe von GitHub.

    exe laden

  2. Starten

    Warnt Windows, klick Weitere Informationen und dann Trotzdem ausführen. Die exe ist noch nicht signiert.

  3. Einrichten lassen

    Brickstrap legt sich nach %LOCALAPPDATA%\Brickstrap und setzt Verknüpfungen auf Desktop und Startmenü. Die geladene Datei kannst du löschen.

  4. Anmelden

    Mit deinem Roblox-Konto auf der echten Seite von Roblox. Updates kommen danach von allein.

Mehr FPS, ohne zu basteln.

Wähl eine Stufe oder stell jedes Flag einzeln ein. Brickstrap schreibt sie vor jedem Start neu, auch nach einem Update von Roblox.

  • Presets: Max FPS, Ausgewogen, Hohe Qualität
  • Nur Flags aus der offiziellen Allowlist
  • Als JSON teilen und einfügen

Deine Spiele, sofort da.

Angepinnte Spiele, zuletzt gespielt und die Reihen von Roblox auf einer Seite. Fährst du über ein Spiel, lädt die Serverliste schon vor.

  • Suche nach Name, Place-ID oder Link
  • Spielzeit nach Tag, Woche und gesamt
  • Läuft im Infobereich weiter, startet sofort

Bereit für deinen Server?

Kostenlos für Windows 10 und 11. Braucht WebView2, bei Windows meist vorhanden.
